# GLMakie Plot Generator

A full-stack pipeline for generating beautiful plots in Julia using GLMakie and serving them through a FastAPI backend to a React frontend.

## Architecture

```
Julia (GLMakie) → Python (FastAPI) → React (Vite)
```

**Stack:**
- **Backend:** Python 3.12, FastAPI, Julia 1.10, juliacall
- **Plotting:** Julia GLMakie
- **Frontend:** React 18, Vite
- **Package Management:** Conda (backend), npm (frontend)

## Setup Instructions

### Backend Setup

1. **Create and activate the Conda environment:**
   ```bash
   cd backend
   conda env create -f environment.yml
   conda activate glmakie-demo
   ```

2. **Install Julia packages:**
   ```bash
   # Set Julia project to use the Project.toml in backend/
   julia --project=. -e 'using Pkg; Pkg.instantiate()'
   ```

3. **Test Julia script (optional):**
   ```bash
   cd julia-src
   julia generate_plot.jl
   # This should create a test plot in backend/outputs/
   ```

4. **Start the FastAPI server:**
   ```bash
   cd backend/app
   python main.py
   # Or with uvicorn directly:
   uvicorn main:app --reload --host 0.0.0.0 --port 8000
   ```

   The API will be available at http://localhost:8000
   - API docs: http://localhost:8000/docs
   - Health check: http://localhost:8000/

### Frontend Setup

1. **Install dependencies:**
   ```bash
   cd frontend
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

   The frontend will be available at http://localhost:3000

## Usage

1. **Ensure both servers are running:**
   - Backend: http://localhost:8000
   - Frontend: http://localhost:3000

2. **Open the frontend in your browser** (http://localhost:3000)

3. **Generate plots:**
   - Select a plot type (3D Surface or 2D Line)
   - Click "Generate Plot"
   - The plot will be generated by Julia, saved on the backend, and displayed in the frontend

4. **View plot history:**
   - All generated plots are shown in the history section
   - Click on a thumbnail to view it full-size
   - Delete plots you no longer need

## API Endpoints

### `GET /`
Health check endpoint that returns server status and Julia initialization status.

### `POST /generate-plot`
Generate a new plot.

**Request body:**
```json
{
  "plot_type": "surface"  // or "line"
}
```

**Response:**
```json
{
  "success": true,
  "filename": "plot_surface_20240101_120000.png",
  "url": "/plots/plot_surface_20240101_120000.png",
  "plot_type": "surface"
}
```

### `GET /plots/{filename}`
Retrieve a specific plot image.

### `GET /plots`
List all available plots.

**Response:**
```json
{
  "plots": ["plot_surface_20240101_120000.png", ...],
  "count": 5
}
```

### `DELETE /plots/{filename}`
Delete a specific plot.

## Development

### Adding New Plot Types

1. **Add a Julia function in `backend/julia-src/generate_plot.jl`:**
   ```julia
   function generate_my_plot(output_path::String)
       # Your plotting code
       fig = Figure()
       # ... create your plot ...
       save(output_path, fig)
       return output_path
   end
   ```

2. **Add the endpoint handler in `backend/app/main.py`:**
   ```python
   elif request.plot_type == "my_plot":
       jl.generate_my_plot(str(output_path))
   ```

3. **Update the frontend dropdown in `frontend/src/App.jsx`:**
   ```jsx
   <option value="my_plot">My Custom Plot</option>
   ```

### Production Deployment

**Backend:**
- Use a production ASGI server (Gunicorn with Uvicorn workers)
- Set up proper CORS origins (replace `*` in main.py)
- Use environment variables for configuration
- Set up proper logging

**Frontend:**
- Build for production: `npm run build`
- Serve the `dist/` directory with a static file server
- Update `API_BASE_URL` to point to your production backend

## Troubleshooting

### Julia Initialization Fails
- Ensure Julia 1.10 is installed: `julia --version`
- Check if GLMakie is installed: `julia -e 'using GLMakie'`
- Try reinstalling Julia packages: `julia --project=. -e 'using Pkg; Pkg.update()'`

### Backend Connection Errors
- Verify the backend is running: `curl http://localhost:8000`
- Check for port conflicts
- Ensure Conda environment is activated

### CORS Issues
- Make sure the backend CORS middleware is configured correctly
- Check browser console for specific CORS errors
- Verify the frontend is making requests to the correct URL

### Plot Generation is Slow
- First plot generation may be slow due to Julia compilation
- Subsequent plots should be much faster
- Consider using a Julia sysimage for production (see `juliacall` docs)
